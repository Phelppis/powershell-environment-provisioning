PUBLICACAO COM GITHUB DESKTOP
1. Extraia o ZIP em uma pasta local, por exemplo: D:\Projetos\powershell-environment-provisioning.
2. No GitHub Desktop: File > Add local repository > Choose; selecione essa pasta.
3. Quando aparecer que nao e um repositorio Git, escolha criar um repositorio nessa pasta.
4. Escreva um resumo para o commit inicial, por exemplo: 'Initial public portfolio sample'.
5. Clique em Commit to main e depois Publish repository.
6. Marque como Public somente apos revisar o codigo e confirmar que tem permissao de publicar o projeto adaptado.
7. Use a descricao e os topicos acima no GitHub.
